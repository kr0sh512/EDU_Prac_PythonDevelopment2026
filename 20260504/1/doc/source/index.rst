MOOD — задание 20260406, задача 2
==================================

**Формулировка задания**

Скопировать решение задачи 1. Реализовать чтение команд из файла при запуске с параметром ``--file <имя>`` (рекомендуемое расширение ``.mood``). В этом режиме интерактивный ввод через ``cmd`` отключён. Между последовательными отправками команд на сервер интервал не менее одной секунды. Для автоматического тестирования при необходимости отключайте бродячих монстров на сервере (флаг ``--no-wander``).
