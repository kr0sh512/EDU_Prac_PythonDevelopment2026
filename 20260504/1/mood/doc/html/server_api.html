Server API¶

TCP session handling and command dispatch for MOOD.

This module defines the asyncio MudServer, player Session records, and the wire-protocol handlers that bridge clients to Dungeon game state.

class mood.server.tcp.MudServer(*, wandering_monsters: bool = True)¶

Bases: object

Game server with named sessions, broadcast chat, and wandering monsters.

The server accepts a login <name> line, then newline-framed commands (move, addmon, attack, sayall). Optional background task moves one random monster every 30 seconds when enabled.

async run_wandering_monsters() → None¶

Sleep 30s, then every 30s move one monster and notify players.

If no legal move exists, the tick does nothing. After a move, players standing on the destination cell receive the same encounter line as if they had stepped onto that monster.
